About & Gallery Feature
=======================

Files:
- about.html
- gallery.html
- style.css
- script.js

How to use:
1. Copy these files into your project folder.
2. Open about.html or gallery.html in a browser.
3. Replace sample text, navigation links, and images to match your team's main website.
4. Commit the files on your feature/about-gallery branch.

Git commands:
git status
git add .
git commit -m "Add about and gallery feature"
